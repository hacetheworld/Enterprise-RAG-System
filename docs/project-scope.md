# Project Scope

## In Scope

### Admin Features

* Login
* Department management
* Employee management
* Bulk employee import using Excel
* Manual document uploads
* External knowledge source registration
* Source-to-department mapping
* Document processing status monitoring

### Employee Features

* Login
* Ask questions
* View AI-generated answers
* View citations
* Open original source documents

### AI Features

* Semantic retrieval
* Keyword retrieval
* Hybrid search
* Reranking
* Grounded answer generation
* Source attribution
* Response caching

### Platform Features

* Department-based access control
* Asynchronous document ingestion
* Structured logging
* Metrics collection
* Dockerized deployment

---

## Out Of Scope

The following features are intentionally excluded from Version 1.

* Multi-tenancy
* Agent workflows
* Voice assistants
* Mobile applications
* Fine-tuned models
* Document editing
* Real-time collaboration
* External identity providers (SSO)
* Multi-language support

---

## Success Criteria

The project will be considered successful when:

* Employees can retrieve information quickly
* Answers contain verifiable citations
* Department restrictions are enforced correctly
* Large document collections can be processed reliably
* Retrieval quality remains high as document volume grows
